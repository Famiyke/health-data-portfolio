05How the Analysis Is Built
Step 01
Source Verification
Each project names its public reference sources and identifies simulated records. Source links do not mean that generated findings reproduce official published estimates.
Step 02
Data Cleaning
Before any analysis, a dedicated script checks for missing values, out-of-range indicators, suppressed cells (CIHI uses "--" and "LV" codes), and coverage gaps across all provinces and years.
Step 03
SQL and Python Analysis
Core questions are answered in SQL for reproducibility and extended in Python for depth. Scripts and sample datasets demonstrate the analytical workflow. Generated results should not be interpreted as validated population findings.
Step 04
Dashboard and Brief
Tableau and Power BI dashboards built for non-technical health audiences. Every project includes a written brief a health director can read in 10 minutes and bring to a planning meeting.
